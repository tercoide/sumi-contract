# sumi-contract

> **Frozen (2026-11-18).** This Gambas PC version is no longer developed. The web versions live in `~/sumi-suite/sumi-contract` (TypeScript) and `~/sumi-suite/sumi-contract-gweb` (Gambas with gb.web.gui, a trial). The `web/` folder here is an old copy: don't work in it.

The paperwork part of the sumi suite: the tasks needed to build a design, its budget, the speciality contractors, the progress of the work and the payments.

Written in Gambas 3. Build and run from the project folder:

    gbc3 -a . && gbx3 .

Smoke test (no window): `gbx3 . -- --smoke-test`
